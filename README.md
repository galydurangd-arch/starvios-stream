# Starvios Live

App Android para transmitir en **Starvios** desde el celular:

- 🎮 Graba la pantalla (ej. Mobile Legends) con el audio del juego y tu micrófono.
- 📷 Usa **otro teléfono como cámara** por Wi‑Fi (modo «Ser la cámara»).
- 🔔 Muestra las **alertas y el chat de Starvios** (seguidores, subs, Starvies, raids) usando la «Fuente de navegador».
- 🏷 Banner con tu nombre, pantalla de «Ya vuelvo» y burbuja flotante de control.

## Descargar
Ve a **Releases** (a la derecha en GitHub) y descarga `StarviosLive.apk`. Instálalo en los dos teléfonos.

## Uso
1. Configuración → pega el servidor, la clave de emisión y la URL de alertas de Starvios.
2. Teléfono cámara: «Ser la cámara».
3. Teléfono del juego: «Preparar directo» → «INICIAR DIRECTO» → elige «Una sola app» → Mobile Legends.
